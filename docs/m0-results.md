## 2. 自动验证的数据

做法：原型常驻后台，用命令行把文件转给它预览（与 OmniZip 调用的路径相同），页面渲染完成后回报时间；经 WebView2 远程调试检查媒体是否在播放，用 PrintWindow 截图确认画面。全程不发送按键。

### 2.1 速度

| 阶段 | 耗时 |
|---|---|
| 冷启动到页面就绪 | 约 420 ms |
| 收到请求到窗口出现（预热窗口） | 0.3–7 ms |
| 文本 136k 字首屏 | 40–60 ms |
| 图片（800×500 PNG） | 约 12 ms |
| PDF（WebView2 内置查看器） | 60–70 ms |
| 视频首帧 | 30–120 ms |
| 系统预览程序（Word / Excel，首次） | 0.8–1.4 s（其中创建 0.45–0.93 s） |

按键到读出选中项的耗时要在 §3 的手动测试中测得（日志里的 `selection read … after the key`）。

### 2.2 格式支持

| 类型 | 可以 | 不行 |
|---|---|---|
| PDF | WebView2 内置查看器，经 `look://` 协议加载，带缩放、翻页、搜索 | — |
| 视频 | mp4（H.264、H.265、AV1）、webm（VP9）、mkv（H.264）、mov（H.264） | avi、wmv |
| 音频 | mp3、flac、ogg（Vorbis）、opus、m4a、wav | wma |
| Office | Word、Excel 系统预览程序，代理进程中运行，以文件路径初始化 | — |

- mkv、mov 能否播放取决于里面的编码；样本是 H.264 + AAC。
- PowerToys 注册的 PDF 预览程序在宿主里显示空白（未深究：PDF 走 WebView2，不需要它）。
- WebView2 的 PDF 工具栏带打印、保存，M2 用 `HiddenPdfToolbarItems` 精简。

### 2.3 内存（私有内存合计，含全部 WebView2 进程）

| 配置 | 空闲（窗口隐藏） | 预览过一次后 | 代价 |
|---|---|---|---|
| 默认（GPU 加速） | 约 200 MB | 约 240 MB | — |
| 隐藏时设 WebView2 低内存目标 | 同上 | 同上 | 只缩小工作集，私有内存不变 |
| 关闭 GPU（`--disable-gpu`） | 约 108 MB | 约 118 MB | **H.265 无法播放**；其余视频改为软件解码 |

Omni Look 进程本身只有 5.8 MB，大头是 WebView2 的 GPU 进程（105–135 MB）。方案 §1.3 的 80 MB 目标在常驻预热窗口下达不到，可选：

- **A. 开 GPU + 闲置释放**：常驻约 200 MB；闲置若干分钟后销毁窗口（降到约 6 MB），之后首次预览约 0.5 s。
- **B. 关 GPU + 闲置释放**：常驻约 110 MB；H.265 交给系统播放器。
- **C. 不预热**：只常驻钩子（约 6 MB），每次预览都冷启动（约 0.5 s）。

### 2.4 选中项读取

- `IShellWindows` 枚举到全部资源管理器窗口；`IShellBrowser::GetWindow` 返回的是标签页窗口（`ShellTabWindowClass`），可以按标签区分。
- 当前标签按"顶层窗口的第一个 `ShellTabWindowClass` 子窗口"判断，多标签时是否可靠待 §3 验证。
- 桌面经 `FindWindowSW(SWC_DESKTOP)` 读取正常。

### 2.5 对方案的修正

- 窗口尺寸按**目标显示器**的缩放计算（多显示器、不同缩放）；大小与位置用 Tauri 接口设置，只有"不激活地显示"用 Win32。
- 预览窗口显示时置顶（`HWND_TOPMOST`），关闭时取消，否则焦点在资源管理器时预览会被它盖住。
- 原型只在方向键之后重读选中项；鼠标点选其他文件时的跟随要订阅视图的 `SelectionChanged` 事件，放到 M1。

## 3. 待手动验证

需要在资源管理器里真实按键，步骤：

1. 运行 `target\release\omnilook-m0.exe`（无窗口，常驻后台；日志在 `%TEMP%\omnilook-m0.log`）。
2. 资源管理器里选中一个文件按 **Ctrl+空格** → 预览出现，焦点仍在资源管理器；再按 Ctrl+空格或 Esc 关闭。
3. 预览打开时按方向键换文件 → 预览跟着换。
4. 同一个资源管理器窗口开两个标签，在**第二个**标签里选文件按 Ctrl+空格 → 预览的是当前标签里的文件。
5. 桌面上选中文件按 Ctrl+空格。
6. 重命名（F2）中、地址栏、搜索框里按 Ctrl+空格 → **不应**弹出预览，输入法切换照常。
7. 预览打开后点一下预览窗口，再按 Esc → 关闭。
8. 选中一个 docx / xlsx 按 Ctrl+空格 → 显示 Office 预览。
9. 运行 `omnilook-m0.exe --quit` 退出。
